Security model

What Vaultly protects against, and what it explicitly does not.

🔒

Cryptography

AES-256-GCM with a 16-byte nonce, PBKDF2-SHA256 at 600k iterations. Master key is never stored; derived on unlock and held in memory only.

📁

Storage

Vault files are 0600, directory 0700. Atomic writes with fsync. Inter-process write lock with stale recovery. Audit log hash-chained (prevHash).

🤖

Agent boundary

Agents cannot call get, env, export or generic run. Secret values are scrubbed from all subprocess output. Only metadata and status cross the boundary.

📋

Audit

Every operation is appended to a hash-chained log. Tampering breaks the chain and is detected by vaultly audit --verify.

📦

Supply chain

SHA-256 checksums, GitHub artifact attestations, immutable releases, cosign keyless signatures, SBOM per archive, pinned actions, Dependabot + CodeQL.

⚠️

Threat model

Protects against: leaked agent transcripts, prompt injection, compromised CI logs. Does not protect against: a compromised host with root access, or a malicious maintainer build.

Verify a download

gh attestation verify ./vaultly -R Growth-Club/vaultly
cosign verify-blob --certificate-identity-regexp 'https://github.com/Growth-Club/.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  vaultly checksums.txt
