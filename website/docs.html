vaultly init
vaultly add prod -k DATABASE_URL -v 'postgres://...'
vaultly list prod
vaultly run prod -- npm run migrate
vaultly deploy api

Core concepts

  • Vault — an encrypted file holding a map of named credentials.
  • Agent mode — default. Blocks value reads; allows approved operations.
  • Human mode — VAULTLY_HUMAN_MODE=1. Full access, including value reads.
  • Deployment target — registered metadata authorizing a fixed deploy.
  • Policy — owner-managed agent-policy.json granting operations per agent.
