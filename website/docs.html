Quickstart

From zero to a deployed Worker in 5 minutes.

vaultly init
vaultly add prod -k DATABASE_URL -v 'postgres://...'
vaultly list prod
vaultly run prod -- npm run migrate
vaultly deploy api
📖

Core concepts

  • Vault — encrypted file holding a map of named credentials.
  • Agent mode — default. Blocks value reads; allows approved ops.
  • Human mode — VAULTLY_HUMAN_MODE=1. Full access.
  • Deployment target — registered metadata authorizing a fixed deploy.
  • Policy — owner-managed agent-policy.json.
  • Trash — soft-deleted secrets, recoverable.
