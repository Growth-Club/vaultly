How it works

Three layers, one trust boundary

Humans hold the control plane. Agents hold nothing.

1

Human control plane

Master password in the OS keychain. Unlock, add, rotate, delete. Agents cannot reach this layer.

2

Agent broker

MCP/CLI tools route through a policy engine. Values are scrubbed from all output; only metadata and status cross the boundary.

3

Approved execution

Deployments and maintenance scripts run with scoped credentials that never appear in build logs.
