Why Vaultly

Built for the agent era. Every competitor was designed for humans typing passwords.

🔐 Zero-knowledge to agents

Agents never see secret values. vaultly get, env and generic run are blocked in agent mode; only approved operations pass.

🛡️ Policy-gated execution

Deployment targets are registered metadata. Agents deploy or run allowlisted maintenance scripts — never arbitrary commands.

☁️ Cloudflare-native

Discover accounts, zones, Workers, D1, R2, KV. Adopt targets from a Wrangler config; bootstrap missing resources on first deploy.

📋 Tamper-evident audit

Every operation is hash-chained (prevHash). Verify the whole chain with one command.

🔄 Encrypted local dev

Production-identical semantics on your laptop. No plaintext .wrangler/state, no real cloud account required.

🤖 MCP server built in

31 agent-safe tools over stdio. Works with Claude Code, Cursor, Codex, OpenCode out of the box.

How it works

Three layers, one trust boundary.

1. Human control plane

Master password in the OS keychain. Unlock, add, rotate, delete. Agents cannot reach this layer.

2. Agent broker

MCP/CLI tools route through a policy engine. Values are scrubbed from all output; only metadata and status cross the boundary.

3. Approved execution

Deployments and maintenance scripts run with scoped credentials that never appear in build logs.
