Parallel execution

Scale to hundreds of agents safely

Launch agents across features, bug fixes, and refactors — all in parallel. Each agent operates within its policy scope. Status at a glance shows which agents are working and which are blocked by policy.

  • Per-agent policy grants (list, read_keys, write, deploy, run)
  • Rate limiting per agent (ops/minute)
  • Vault-scoped access (allowlisted vaults only)
  • Expired credentials block subprocess execution

Isolation

Changes are isolated

Each agent runs in its own policy scope. No overwriting each other's secrets. Review and merge work when you're ready. Secret versioning and trash provide full rollback capability.

  • Per-secret version history (100 versions)
  • Soft delete with trash + restore
  • Secret references (${KEY}) for composition
  • Rekey (rotate master password) with rollback

FAQ

Frequently asked questions

How is Vaultly different from just running Claude Code in a terminal?

Vaultly sits between your agents and your secrets. Agents request approved operations through the policy engine; secret values are never returned, logged, or placed on a command line. Every operation is hash-chained in an audit log.

I already use an IDE like Cursor, is this for me?

Yes. Vaultly works alongside any IDE or terminal. Use vaultly mcp to expose 38 agent-safe tools to Claude Code, Cursor, Codex, or OpenCode.

Which AI coding agents are supported?

Claude Code, Codex, Cursor, OpenCode, Gemini, Mistral, Devin, Aider, and any agent that speaks MCP or can shell out to the CLI.

How does the policy system work?

An owner-managed agent-policy.json grants operations per agent, scoped to specific vaults. Operations include list, read_keys, write, delete, deploy, run, cf_api, github_sync, secret_sync, admin. Agents are rate-limited per minute.

Is Vaultly free to use?

Yes. MIT licensed, free forever, self-hosted. No SaaS required. A managed platform with team features is coming.

Can I use my own API keys?

Absolutely. Vaultly never proxies model calls or locks you to a provider. Bring your own Cloudflare, Vercel, GitHub, and LLM API keys.

Is Vaultly open source?

Yes. Full source on GitHub under MIT. Inspect, audit, and contribute.

What platforms does Vaultly run on?

macOS, Linux, and Windows. Single static binary, no runtime required.
